# YouTube Muusikamängija

Lihtne veebirakendus YouTube'i muusika kuulamiseks. Pole vaja YouTube'i avada – kõik toimib ühes kohas.


## Funktsioonid

- **Muusika esitamine** – YouTube'i lugude mängimine, automaatne järgmine lugu, eelmine/järgmine nupud
- **Otsing** – otsi loo nime või esitaja järgi
- **Meeleolufiltrid** – 10 filtrit: energiline, lõõgastumine, pidu, treening, romantika, kurb, keskendumine, uni jt
- **Esitusloendid** – meeldinud lood ja järjekord (salvestub brauserisse)
- **Külgriba** – saab peita, et rohkem ruumi saada
